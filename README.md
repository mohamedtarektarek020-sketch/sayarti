# سيارتي — بوابة السائق

صفحة للسواقين لمعرفة مواعيد أوراق السيارة وتغيير الزيت. البيانات متشفّرة برقم اللوحة والإقامة.

## تحديث البيانات تلقائيًا
`tools/gen_portal.py` بيبني `data.json` والملفات المتشفرة في `f/` من حالة الداش بورد.
فهرس مفاتيح الملفات سري ومش في الريبو — محفوظ في الداش بورد (vault/portalIndex).
